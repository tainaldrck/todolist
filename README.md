# 📝 Todo List

> Une application web simple pour organiser ses tâches et améliorer sa productivité au quotidien.

## ✨ Fonctionnalités

- ➕ Ajouter une tâche
- ✅ Marquer une tâche comme terminée
- 📋 Consulter sa liste de tâches

## 🚀 Installation

Clone le dépôt :

```bash
git clone https://github.com/tainaldrck/todolist.git
```

Accède au dossier :

```bash
cd todolist
```

## 🎯 Objectif du projet

Ce projet a pour objectif de pratiquer les bases du développement web avec HTML, CSS et JavaScript, ainsi que l'utilisation de Git et GitHub.
